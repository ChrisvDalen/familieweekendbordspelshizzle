# Familieweekend Bordspel Scorebord

Statische website (GitHub Pages) om bij te houden wie welk bordspel gewonnen heeft.

- Vul per potje het spel, de datum, de deelnemers en de winnaar(s) in.
- Het leaderboard toont overwinningen, gespeelde potjes en winstpercentage, ook per spel.

## Let op: opslag

Gegevens staan in de `localStorage` van de browser: alleen op dat ene apparaat.
Gebruik **Exporteren** voor een back-up. Wil je een gedeelde stand voor iedereen,
zet het geëxporteerde bestand als `data.json` in deze repo; een browser zonder
eigen gegevens laadt dat automatisch als startpunt.

## Publiceren

Repo-instellingen → Pages → Source: *Deploy from a branch* → kies `master` en `/ (root)`.
